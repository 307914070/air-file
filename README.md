# FileAir - 极简局域网文件互传工具

非常轻量的局域网文件共享服务。在同个 Wi-Fi 或局域网下的电脑、手机均可通过浏览器直接访问，支持拖拽多文件极速上传、下载与删除。

---

## 🌟 功能特性

- **拖拽上传**：页面顶部大区域支持直接拖拽文件（单文件/多文件）上传，也可点击选择。
- **实时进度**：上传时显示进度条与百分比。
- **即时查看**：上传完成自动刷新文件列表，同时支持后台自动轮询（他人上传后数秒内自动呈现）。
- **文件操作**：一键下载、安全删除、文件名即时搜索过滤。
- **中文与重名处理**：完美支持中文文件名，若遇重名自动按序号命名，防止误覆盖。
- **自适应设计**：手机、平板、电脑浏览器均可无缝访问。
- **局域网提示**：启动时自动打印所有可用局域网 IP 地址，并在网页顶部清晰标示。

---

## 🚀 启动运行

```bash
# 启动服务
npm start
# 或者
node server.js
```

启动后控制台会输出局域网访问地址，例如：
```text
==================================================
🎉 局域网文件共享服务已启动！
- 本机访问:   http://localhost:3000
- 局域网访问: http://192.168.1.48:3000
==================================================
```

局域网内的其他电脑、手机直接打开 `http://<你的IP>:3000` 即可使用！
